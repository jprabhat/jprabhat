<h2 align="center">🚀 About Me</h2>

Associate Software Engineer at LeanQubit, building production React and TypeScript applications for enterprise manufacturing operations software. 

Recent work includes  reusable, multi-view  component (table, grid, list, and flow views) with configurable field selection and live preview, and migrating a screen's API integrations to a structured service/hook architecture built on React Query. I've also worked through bugs like stale closures, generic type contravariance in reusable components, and cache key collisions — the kind of problems that show up once an application is used at real scale.

B.E. in Information Technology, graduated May 2026. Currently deepening system design fundamentals and shipping personal projects end-to-end, with a focus on component architecture that holds up under real usage, not just demos.
